## Findings

`src/sim/src/placement.cpp:75` and `:127`.** The added minimum-level check and
ramp/pier refusal always run, including with default `Rules{}`. The documented
and emulated original accepts a class-`0x4000` road at levels 0/16 and permits a
road to replace a compatible ramp/pier piece. There is no hashed rule selecting
either new restriction. Thus callers cannot reproduce these researched road
predicates using the original rule settings, and a mod cannot choose the
documented alternative without changing engine code. Labelling the differences
ADAPT and proving the enhanced expectations does not provide that separation.
The common instructions require selectable gameplay improvements. Add two
explicit persisted/hashed options and thread their actual values into the
default placement path. Preserve the original class-`0x1000` level/slope tests
and the already accepted authoritative-height adaptation in both settings.

**[P3] Remove the unsupported claim that old road recordings cannot exist —
`docs/sim/road-placement.md`, section 10.** A command can be recorded while being
refused with `Unsupported`; it need not have succeeded to appear in a replay.
Describe the behavioral compatibility change without inferring that no earlier
recording contains a road command. Separate format compatibility, selected-rule
identity and behavior at a particular build. Fold this wording correction into
the bounded closeout; no additional test campaign is needed for the prose.
