## Actual callers and first differences

`src/sim/src/replay.cpp::run_turn` applies commands, then calls `World::advance`
exactly `steps` times with `turn.step_ms` each time. D6 moves the world out of
OpeningLoad and calls this function directly; it never starts PlayRunner.
`src/app/src/play.cpp` instead derives its per-step interval from speed, normally
10 ms, and executes ten steps per turn at 100 %. The queued/live driver is not tested here.
The expansion harness uses `Recorder::submit` (World::apply) and one 1000 ms
advance per poll. Commands in a block cause no advances.

## Regression, validation and limits

The registered cheap sim case tests 0, 1 and 1000 ms across ten visits, a zero-step
command-only boundary, clock-only 1 + 1 versus 2 ms accumulation, and a deliberately
different interval which changes state. Zero-time subsystem visits are not treated
as no-ops. A private test-only mutation replaces ten visits by one (exactly one
replacement, recorded before/after SHA256). It fails the hash assertion and log
entry count (2 versus 11) at 0 ms; the existing legal command-before-steps test
passes. The positive source is restored byte-for-byte and rebuilt before sanitizer
validation. No mutant or production change is committed.

Gate receipts and content hashes follow below. Initial and diagnostic runs remain
preserved; they were not overwritten. Original files are read-only and no original
bytes, asset listings or host paths are published. The Windows consumer delta is
only the updated D6 registered title (W4 marker retained), its checked schedules,
and the new sim timing regression; no application or command API changed.
Existing native/replay/pin coverage at accepted 9edb151c is reused because no
production, state-field, fixture, oracle or pin bytes change; the two existing
run_turn regressions are also executed here. No new persistence path is introduced.

NOT_RUN: physical PlayRunner/window timing, Windows/original-runtime/HE execution,
full suite, 900000-tick town campaign, full pins regeneration/check, or retrospective
state-134 execution. These are not claimed by the headless diagnosis.
