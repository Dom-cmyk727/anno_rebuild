## The game-file run on this PC: memory

This PC has 31.1 GB of RAM. During the review, WSL held 5.7 GB of it while the C gate ran. The two full MSVC runs used
`ctest -j 16` with `ANNO_TEST_THREADS=16`. In both, the shared memory coordinator refused corpus items with
`low-memory stop` once free memory fell below 2 GB:
- A's run: 13 refusals, 487 s, with no WSL gate running;
- B's run: 4 refusals, 805 s.

Those tests did not execute. A full game-file run therefore doesn't execute every test unless memory is controlled.
- **Recommendation for the owner-rule run on `main`:** make sure no WSL gate is running first.
- **If refusals remain:** use fewer threads or jobs, and record the setting.
- **Each refusal:** report it as not run, with its name and reason, never as a failure or a pass.
