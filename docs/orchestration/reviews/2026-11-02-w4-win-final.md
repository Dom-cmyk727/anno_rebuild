## Findings and required completion gaps

**[P2] Propagate child sanitizer diagnostics into the viewer verdict —
`tools/test/viewer_wiring.py:121–125`.** The newly instrumented viewer runs with
stderr redirected to a sidecar and stdout discarded. The wrapper reads stderr
only to look for expected SDL messages; it never rejects sanitizer reports or
exposes them to the canonical gate. App UBSan is recoverable, so exit zero is
not sufficient. With the published wrapper, a complete matching positive
fixture passes; the same fixture emitting a UBSan `runtime error:` only on
stderr also returns zero and prints PASS. A representative ASan diagnostic
with fixture exit zero passes too. These are synthetic diagnostic-propagation
probes, not claims that the actual viewer had UB or that ASan normally returns
zero. The manually scanned three real runs support those individual runs, but
do not close the persistent verdict gap. Retain and scan child diagnostics,
fail on reports, and test that behavior through the public wrapper.

**[P2] Match the complete parsed script, not just its first arguments —
`tools/test/viewer_session.py:22–34`.** The new validator reduces each non-wait
instruction to line number, verb and first argument; the producer logs that
same reduced form. Thus a valid-format log for `look 1 2` also passes when the
invoked script says `look 1 999`. The public CLI reproduces this with exit zero
and `PASS changed-second-argument`. Later arguments of expectations and all
wait arguments are similarly absent from identity. This can bless the wrong
script revision when revalidating retained sessions, despite different target
coordinates or assertions. Add full script identity from the viewer's parsed
input and compare it, while preserving ordered completion checks. This is not
a requirement to defend against a child deliberately forging evidence; trusting
the runtime recorder is appropriate, but its record must distinguish meaningful
input changes.

Both gaps can be corrected without repeating corpus or adapter matrices.
The existing 14 public viewer contracts pass on the reviewed tools; they do not
exercise these counterexamples. This review did not find a further qualifying
rendering or reclaimer behavior defect in the changed source.
