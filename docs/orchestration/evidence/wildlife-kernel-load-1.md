## Source profile and range policy

D: Welt `0x10084670–0x10084698` zero-extends selector at island +0xc0 and uses
RVA `0xca008 + 25*selector`. Seven observed selectors 0–6 are supported, not a
claim of the complete table extent or an engine-wide climate limit. PE32/I386,
GOG stamp `0x44c0c353`, image size `0xf1000`, base `0x10000000` are layout checks,
not authentication. Returned SHA identifies the actual supplied bytes.

Only additive private-helper fields and a separate readonly range query are
introduced. Existing walk/resource/anbau offset mapping and error priority stay
unchanged. The new query counts intersections with max(virtual, raw) ranges,
requires exactly one, and requires the whole window within both virtual and raw
extent, the selected section within image bounds, full raw backing, READ and no
WRITE. All additions widen before checking. Empty sections cover no byte.
No virtual zero-fill, raw padding, first-overlap selection or general PE emulator.
