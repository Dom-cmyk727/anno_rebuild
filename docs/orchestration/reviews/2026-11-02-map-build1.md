`src/sim/tests/founding_assets_test.cpp:1250` and
`src/sim/tests/nav_scale_test.cpp:452`.** The new cases use fixed names
`anno_sail_export_test` and `anno_nav_scale_writer_test` under the system temp
directory, then recursively remove them. Two processes running these cases
(for example separate build configurations or worktrees) delete each other's
inputs and output. On the exact E1 Debug binary, a serial control passes both
cases and all 20 assertions; twelve invocations on two concurrent workers give
three successful and nine failed processes. Failures include a successful-write
control returning an error, `file_size` finding no summary, and `remove_all`
throwing `Directory not empty`. This is shared test state, not a placement or
file-publication failure. Allocate an exclusively created directory per test
invocation and clean up only that directory; retain the actual writer and all
assertions. No global serialization or infrastructure rewrite is warranted.
