13(counter0..12). Empty/unknown tokens count; after 13, tail bytes are ignored.

capacity, fixed map count or hardcoded installation list.

exact, first match wins, then OR 1<<(index−56). Game jump case 0x1000346b–0x100034ad
calls 0x10013be0; range0x10013c52–0x10013c63 uses pointer table 0x100251f8.
Null -> 0x100261e8 at0x10013cde–0x10013ce7. It is immutable original-image name
data, not TypeRegistry mod names or figure/building ids. The new bounded name
reader reuses the existing checked PE view, same supported identity, dynamic
owned strings and fallback. No original name list is compiled into new code.
New data inspection has no PE encoder or executable loading; processed header

placement, dry-field or preseeded-bit consumer policy is derived or activated.

a nonempty header needs names, no whole-map copies or shared-const mutation.
