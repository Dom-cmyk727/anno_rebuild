# cargo_load_vectors.txt - hand-derived cases of the manual own-warehouse -> ship LOAD (MAP-CARGO-2 L1).
# Format and reference: tools/cargo_ref.py (docstring). Contract: docs/sim/ship-cargo.md section 12; evidence:
# docs/re/ship-cargo.md section 11. This file is separate from cargo_vectors.txt (the unload, read by the C++ unload test)
# so the two expectations cannot be confused. EVERY expected value was derived by hand from section 11.3 / 12 BEFORE
# tools/cargo_ref.py plan_load or orig_load computed anything (the derivation is in the comment above each case).
#
# Units: raw 1/256 ton ("units"); a request is in whole tons (T = 256). Goods: 26 food, 41 tools, 42 wood.
# Defaults: holdcap 12800 (50 t per hold, LOGIC[0x11] << 8 of the shipped 1502), goods_count 56, storecap 12800 (unload steps),
# nholds = the number of `hold` lines of the first ship (the type's n0; `nholds none` = the type has no cargo facts).
#   load   SHIP IDX G TONS -> ok MOVED RESOLVED | reject REASON     (IDX = the named/preferred hold, RESOLVED = the hold used)
#   unload SHIP IDX G TONS -> ok MOVED | reject REASON              (the existing unload rule, for round trips; IDX >= nholds is BadIndex,
#       MAP-CARGO-3 C1: the original bounds the unload by n0 alone, 0x100ac476)
#   nholds_b N : the type's second hold group (hold_count_b), default 0; never a transfer bound
#   orig RET RESOLVED HOLD STOCK : the ORIGINAL arm (0x100ac360 flag 0, 32-bit semantics, hold amount a u16, signed compares) for the FIRST
#       `load` of the case: return value (signed), the hold it used (-1 when it returned 0), that hold afterwards (goods:units; hold 0 when -1) and the
#       stock of the requested goods afterwards. Evidence of agreement or of a defect, never an engine expectation.
# Rebuild rule (restated for the hand derivation): preferred = the named hold if it holds G and has >= 256 units free, else the search
# over holds 0..n0-1: the first EMPTY hold (goods 0 and amount 0) unless a hold of G with free > 0 exists, then the one with the most free
# (strictly greater, lowest index on ties); x = min(tons*256, holdcap - amount, floor256(stock)); StockShort when floor256(stock) = 0.
